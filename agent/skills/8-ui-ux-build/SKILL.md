# 8-ui-ux-build — UI Execution and Flow Refinement

Use this skill only after the UX discovery skill has been reviewed and approved. This is the implementation phase for product feel, interaction clarity, and visual polish.

## Goal

Apply the approved UX direction to the actual app. Keep the experience simple, grounded, readable, and emotionally supportive. Make the interface feel like a useful personal companion, not a generic website or a spammy app shell.

## Execution rules

- Start with the user flow, not decoration.
- Fix the arrangement of screens before polishing tiny visual details.
- Replace generic language with real, respectful, human wording.
- Reduce visual clutter and over-designed cards.
- Keep layouts spacious and readable.
- Prioritize clarity, warmth, and trust over cleverness.
- Preserve the app's pastel identity without turning it into a noisy template.

## Focus areas

### Flow clarity
- Is the user path obvious and gentle?
- Are there too many steps or too much friction?
- Does the app help the user understand what happens next?

### Copy quality
- Remove robotic or overly polished phrases.
- Write in a tone that sounds honest, calm, and supportive.
- Keep the product language natural and not AI-generated sounding.

### Visual calm
- Use consistent spacing and rhythm.
- Reduce crowded sections and repetitive card patterns.
- Ensure buttons, headings, and content read as a single cohesive experience.

### Product trust
- Avoid looking like a template or a scammy app.
- Make the experience feel believable and subtle.
- Keep the UI supportive without feeling forced or dramatic.

## Build checklist

1. Review the approved UX direction.
2. Identify the first screen and flow improvements that matter most.
3. Update the copy and tone before adding more design polish.
4. Improve the hierarchy of text and actions.
5. Remove anything that feels template-heavy or over-marketed.
6. Validate the flow with a real user pass through the screens.

## Done means

The app feels coherent, human, and easy to use. The screens are readable, the copy feels natural, and the user journey is obvious without feeling engineered or overwhelming.

## Important

If the UX direction is not approved, pause and return to the discovery skill. Do not begin polishing without intent.
