# Mydobby Demo Checklist

## 1. Run the app

Requirements:
- Node 20+
- npm installed

Commands:

```bash
cd /Users/taranjeetsingh/Desktop/Hackathons/my-hackathon-app/mydobby
nvm use 20
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## 2. Exact demo flow

Use this exact demonstration path for the strongest presentation:

1. Open the app.
2. Pick a profile name like “Aisha” or “Sam”.
3. Choose a messenger icon (example: Owl or Phoenix).
4. Enter this text:

```text
I feel behind on work and I’m overwhelmed. I only have 20 minutes and medium energy.
```

5. Select:
   - Time: 20 min
   - Energy: medium
6. Enter a goal such as:

```text
Finish my work update
```

7. Wait for the app to show the suggested next step.
8. Show the plan summary and next-action recommendation.
9. Navigate to the letter/history section.
10. Show generated month or milestone letter output.

## 3. What to say while demoing

### Intro
“People don’t need more pressure—they need a calmer way to know what matters.”

### Product explanation
“Mydobby helps users dump what is on their mind, choose what they actually have time and energy for, and turn that into one realistic next step.”

### Proof of value
“You can type anything you’re feeling, select your energy and time, and the app turns that into a focused plan instead of a giant list of tasks.”

### Letter angle
“We also added future-self reflections so the app helps people look back at progress without guilt.”

## 4. Strongest 2-minute pitch

“Hi everyone, we built Mydobby—a calm check-in app for people who feel overloaded and don’t know what to do next. It helps them turn messy thoughts into clear priorities and one realistic next step. The app lets a user write anything they’re feeling, choose how much time and energy they have, and receive a simple plan that respects their real capacity. We also added future-self letters so the user can reflect on progress, not just pressure. This is not another productivity app—it is a calmer system for decision-making and sustainable momentum.”

## 5. What to show on screen

The most important screens to show in order:
- landing page / welcome
- profile setup
- mind dump input
- time + energy choices
- goal input
- recommendation card
- letters/history output

## 6. Keep it polished

Avoid these mistakes:
- showing too many screens
- reading every UI label out loud
- explaining internal implementation details
- wasting time on non-essential screens

Instead:
- focus on one clear user story
- keep the input realistic
- emphasize that the app reduces overwhelm and creates action

## 7. Final reminder

The heart of this project is:

“Mydobby turns overwhelm into clarity, one small action at a time.”
